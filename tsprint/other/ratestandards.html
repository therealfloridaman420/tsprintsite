Rate Standards

This page contains the requirements for different level ratings, and the standards for all of them, for a list of creators and the scores of their levels, see the Creator Leaderboards

No Rating : 0 Creator Points

Levels that either with or without the outdated version subtraction would still get 0 creator points, will not be rated. It is probably harder to get a level in this section than it is to get a feature

Levels rated 12* or higher difficulty will be put into this catagory if no proof of completion is sent with the level file (can either be a youtube video, an mp4 sent in discord, or really any other video sending method)

Possible Rating : 1-2 Creator Points

Levels made in the latest version that don't meet the standards for 3 creator points will not be rated, if a level would get 1 or 2 creator points after subtracting the amount for building in an older version, then it might still get rated

Basic Rate : 3-6 Creator Points

  • Level must be 20 seconds or longer, there can be filler gameplay as long as the level is 20+ seconds
  • Level must contain a "Level End" trigger

Feature : 7-10 Creator Points

  • Level must be 30 seconds or longer with minimal filler gameplay
  • Level must contain a "Level End" trigger

Levels made in older versions of the game will be rated first under the standards of that version then a certain amount will be subtracted to encourage levels to be made in the latest version

If your level was made with an editor version that wasn't the latest at the time of its upload, then the following amounts will be subtracted

  • 1.1 : This version is the latest, so nothing is subtracted
  • 1.0 : -1 Creator Point
  • 0.7-0.9 : -2 Creator Points
  • 0.5-0.6 : -4 Creator Points
